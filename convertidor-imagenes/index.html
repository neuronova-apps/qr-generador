Configuración

Puedes seleccionar varias imágenes. Para GIF animados o imágenes de varias páginas solo se procesa el primer fotograma visible.

La calidad afecta principalmente a JPG y WebP. PNG utiliza compresión sin pérdida y el navegador puede ignorar el nivel seleccionado. La disponibilidad de AVIF varía.

Selecciona una o varias imágenes para empezar.
